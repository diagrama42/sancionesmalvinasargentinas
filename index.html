Documentación: API de Sanciones

Esta API permite verificar si una empresa, persona, país o dirección IP se encuentra dentro de una lista restringida de entidades sancionadas.

1. Endpoints y Parámetros

La API responde a peticiones GET o POST. La URL base asumida es sanciones.php.

  • q (String): Busca coincidencias en nombres de empresas o actores (ej. Navitas, Samuel Moody).
  • country (String): Busca si el país está en la lista de regiones sancionadas (ej. Reino Unido, Israel, Canada).
  • ip (String): Geolocaliza la dirección IP y verifica si el país resultante tiene sanciones (ej. 142.250.217.110).

Nota: Puedes combinar los parámetros en una sola petición.

3. Ejemplo de Integración en JavaScript

Así es como puedes consumir esta API desde tu propia aplicación utilizando fetch():

// 1. Definir los parámetros de búsqueda
const params = new URLSearchParams({
    q: 'Fugro',
    country: 'Países Bajos'
});

// 2. Hacer la petición a la API
fetch(`sanciones.php?${params.toString()}`)
    .then(response => response.json())
    .then(data => {
        if (data.is_sanctioned) {
            console.warn("ALERTA: Entidad sancionada detectada.");
            console.log("Coincidencias:", data.matches);
        } else {
            console.log("La entidad está limpia.");
        }
    })
    .catch(error => console.error("Error en la API:", error));
